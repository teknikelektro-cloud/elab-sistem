# E-Laboratory

Sistem Informasi Laboratorium Teknik Elektro - Universitas Teknologi Sumbawa

## Fitur
- Manajemen User (Admin, Dosen, Asisten, Ketua, Mahasiswa)
- Praktikum & Penjadwalan
- MK Praktikum (Kurikulum)
- Inventaris Alat
- Peminjaman Alat
- Absensi & Nilai
- Surat Bebas Lab
- Surat Tugas & Sertifikat Asisten
- Penandatangan Digital
- Dashboard Statistik

## Teknologi
- HTML/CSS/JavaScript (Single Page Application)
- Supabase (PostgreSQL Database)

## Deploy
Upload `index.html` ke GitHub Pages, Netlify, atau hosting statis lainnya.
