Ajukan Peminjaman Alat

👤 🎓 📅
📋 Syarat & Ketentuan Peminjaman Alat
  1. Peminjam wajib menggunakan alat sesuai dengan fungsi dan peruntukannya.
  2. Alat harus dikembalikan dalam kondisi bersih, lengkap, dan baik sesuai tanggal yang telah disepakati.
  3. Peminjam bertanggung jawab penuh atas kerusakan atau kehilangan alat selama masa peminjaman.
  4. Jika terjadi kerusakan, peminjam wajib melaporkan kepada admin laboratorium dan bersedia mengganti atau memperbaiki alat tersebut.
  5. Keterlambatan pengembalian alat dikenakan sanksi berupa denda atau penangguhan hak pinjam.
  6. Peminjaman tidak dapat dipindahtangankan kepada pihak lain tanpa persetujuan admin.
  7. Alat yang dipinjam hanya boleh digunakan di lingkungan kampus kecuali mendapat izin khusus dari admin laboratorium.
  8. Peminjam wajib menjaga kebersihan dan keamanan alat selama digunakan.

Cara setup EmailJS (gratis):
1. Daftar di emailjs.com
2. Tambah Email Service (Gmail/Outlook) → salin Service ID
3. Buat Email Template → salin Template ID
4. Buka Account → API Keys → salin Public Key
